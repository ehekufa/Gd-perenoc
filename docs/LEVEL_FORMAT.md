# Формат уровня `.lvl`

Уровни в игре — обычные текстовые файлы. Уровень по умолчанию лежит в
`assets/levels/point_of_no_return.lvl` (это ваш файл уровня).

## Символы

| Символ | Значение |
|---|---|
| `.` | пусто |
| `1` | блок |
| `2` | шип (остриё вверх) |

Также работают: `0`, `_` и пробел — пусто; `X`, `B` — блок; `^`, `S` — шип.

Один символ = одна клетка сетки = один блок игры (48 px).

## Раскладка

* каждая строка файла — ряд сетки;
* **первая** строка сетки — самый верхний ряд, **последняя** — опора на
  «землю» (в игре есть бесконечная земля, но обычно нижний ряд делают из
  блоков, как в текущем уровне);
* ширина уровня = длина самой длинной строки; более короткие строки
  автоматически дополняются пустыми клетками;
* финиш — правый край сетки: как только кубик доезжает до него, уровень
  пройден.

Пример (7 столбцов, 3 ряда):

```
.......
.......
.2...2.
1111111
```

Ряды блоков автоматически склеиваются в один объект: стена высотой 5 клеток
становится одним блоком, а не пятью.

## Комментарии и директивы

Строки, начинающиеся с `#` или `;`, игнорируются.

В начале файла можно задать параметры:

| Директива | По умолчанию | Значение |
|---|---|---|
| `!name ТЕКСТ` | `POINT OF NO RETURN` | название (пишется в начале уровня) |
| `!spawn 6` | `6` | столбец, в котором появляется кубик |

## Как играть свой уровень

```bash
./build/point_of_no_return --level assets/levels/my_level.lvl
```

или положите файл в `assets/levels/` и укажите путь через `--level`.
Для Android файлы уровней лежат в `assets/levels/` (они попадают в APK
как assets).

## Как проверить, что уровень проходим

В игре есть автопилот: он ищет последовательность прыжков и честно
прогоняет её через физику.

```bash
./build/point_of_no_return --selftest --level assets/levels/my_level.lvl
```

Вывод `SELFTEST OK` означает, что уровень проходим (и печатает, за сколько
прыжков). В самом приложении демо-режим включается клавишей `F1`
(или ключом `--autoplay`).

## Правила игры

* кубик бежит вправо сам, скорость постоянная;
* прыжок — `Space`, `↑`, `W`, левая кнопка мыши или тап по экрану
  (на телефоне можно просто держать палец);
* касание шипа или стены — смерть и рестарт с начала (счётчик попыток);
* высота прыжка ≈ 2.7 блока, длина ≈ 4.8 блока — этого хватает, чтобы
  перепрыгнуть 3 шипа подряд или заскочить на платформу высотой 2 блока.
